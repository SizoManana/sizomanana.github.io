How I work

The loop, in the order I actually run it

Clients find the first three steps slow. They are the reason the recommendations end up being about their users rather than about my taste.

  1. Audit against heuristics, and score itSix dimensions, scored, so the argument is about the scoring rather than about whose opinion is better.
  2. Check whether the tracking is telling the truthIt usually is not. Form starts firing on page view is the single most common thing I inherit.
  3. Rebuild the instrumentation and capture a baselineGA4 and Google Tag Manager, event and parameter design, then sixty to ninety days of clean data.
  4. Segment before concludingA blended conversion rate hides more than it shows. The Dayshape case study is entirely about this.
  5. Write hypotheses and prioritise themStated as a prediction with a named metric, so it can be wrong.
  6. Design and get it builtI implement 70 to 80 percent of my own work, which keeps the design honest about what is buildable.
  7. Test where the traffic supports itVWO and Convert. Where volumes are too thin for a valid test, I say so instead of pretending.
  8. Come back and validate against the baselineIncluding the part of the movement that was measurement correction rather than behaviour change.

About this page

It seemed fair to hold my own site to the standard I audit other people against, so here is what it does and why.

  • No web fonts. The typefaces are whatever your device already has, so there is nothing to download and no invisible text while a font loads.
  • No analytics, no cookies, no third party scripts. Nothing here tracks you. The one embed on the site, a video, loads only if you click it.
  • Every image ships its own dimensions, so the layout does not jump while the page loads, and everything below the fold is lazy loaded.
  • Light and dark follow your system setting. Both were designed, not inverted. Three of the projects below shipped in both modes, so it would be odd if this page did not.
  • It works on the keyboard. Visible focus rings, a skip link, semantic headings, real alt text, and it respects a reduced motion preference.
  • Static HTML and CSS, hosted free. No framework, no build step, no server. About 20 kilobytes of CSS for the whole site.
